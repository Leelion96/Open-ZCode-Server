# 服务名称与版本

- 服务使用固定名称 `Open-ZCode-Server`，用于 OpenAPI 标题与接口浏览页面标题；不提供名称配置、品牌开关或启动时的品牌文件读取。
- 开发者需要改名时直接修改源码。名称不参与数据库、内容目录、容器或存储卷命名。
- 软件版本唯一来源为 `package.json.version`，由 common 的异步加载函数在生成文档时读取；不在请求路径读取文件。
- API 版本仍由 `/api/v1` 路径表达，数据库 schema 版本由迁移与数据库模块标记控制，均不随软件版本改变。
- 文档关闭时无需加载文档版本信息。缺失或无效的软件版本只输出固定诊断，不回显文件内容。
- 保留中性错误信封与既有公共数据、占位状态和文档交互，不修改客户端或已有部署数据。
- 验收：真实 HTTP 返回固定 OpenAPI/HTML 标题，文档版本与实际 package 版本一致；所有现有接口状态保持一致，Docker 构建不再要求品牌配置目录。
