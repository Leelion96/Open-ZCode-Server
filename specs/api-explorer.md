# 接口浏览与调试入口

## 行为与范围

- 使用 Swagger UI，在 `/docs` 浏览全部31个清单接口并手动执行真实请求；不接入客户端，不新增独立前端项目。
- 以 `specs/api-inventory.json` 为状态、预期状态码和分组的权威来源；Nest/Zod 生成的 schema仍为已注册接口的 HTTP契约来源。文档不得注册那14 个排除路由。
- 每个清单操作有中文用途、状态标签、预期状态码说明。辅助的健康和配置文件下载接口继续可见。
- 已实现操作标注 `[200 已实现]`，占位标注 `[501 占位]`，未提供标注 `[404 不提供]`。501/404是预期业务状态，但实际响应仍显示真实错误；不能显示成成功响应。
- configs预填 `app_version=3.14.3`、`platform=darwin-arm64`；路径参数使用 `demo`。暂缓或不提供的 POST只提供探测示例，不宣称完整还原官方请求体。文件占位使用 multipart表单，不真实保存文件。
- 参数与结果面板由 Swagger UI所有；用户点击 Try it out / Execute才请求，不自动运行接口。当前页面相对 origin是唯一默认请求目标，不指向官方域名或其他项目服务。
- 文档参数以 `(in, name)` 唯一标识去重，兼容编译反射和显式DTO元数据同时产生的重复项；开发与编译运行都只展示一份字段，不改变HTTP参数校验。
- 文档采用OpenAPI 3.1，以正确展示Zod的可空字段；只改变文档格式，不改变产品API的JSON响应。
- 请求支持 GET/POST，提供搜索、分组折叠、深链接、复制请求和格式化结果。授权不持久化，关闭远端 validator，静态 JS/CSS在服务端本地分发。
- `OPENAPI_ENABLED=false` 同时关闭页面、原始文档和其静态资源入口。

## 所有者与依赖

- `documentation` 负责启动时异步加载、校验清单以及合成文档，不持有产品业务状态、不写数据库、不添加 HTTP Controller。
- App启动组合层调用公开文档入口，SwaggerModule负责 HTML、静态资源及原始文档。Controller保持原状，业务schema不为文档改变。
- 每个已实现/占位项必须匹配一个已注册 OpenAPI操作；缺失、状态/方法重复或错误状态码导致启动失败，避免文档悄悄偏离实现。
- UI扩展仅复用 Swagger UI与一份轻量样式。没有其他页面、管理后台、编辑器、数据库浏览器或内容预览功能。

```text
API清单 + Nest/Zod文档 → 启动校验/合成 → Swagger UI
                                              ↓ 用户点击 Execute
                                    当前服务真实HTTP → 原始响应面板
```

## 设计与布局

- 面向开发者的单页接口手册，标题固定为Open-ZCode-Server；用途与状态说明使用中文，Swagger原生Try it out / Execute等技术按钮保留英文。API路径、参数与响应占据主要空间。
- 控件、请求loading与结果面板由本地Swagger UI提供；复用其字体、间距与控件形状，不增加网络字体、品牌主题或独立前端。HTTP方法颜色只表达方法，功能状态另用文字标注。
- 使用系统中文fallback与技术文本字体；31个清单接口通过搜索、分组折叠与文档滚动浏览，无分页或无限滚动。接口正文默认折叠，长JSON允许内部横向滚动，验证桌面与390px窄屏。
- `src/documentation/styles.ts`是自有样式的唯一实现。滚动条thumb/track/hover为`#9aa2ad` / `#f3f4f6` / `#6b7280`，键盘焦点为`#2563eb`、2px描边与2px偏移；保留稳定滚动条空间、textarea固定尺寸及长路径换行。
- 保留forced-colors默认对比度与prefers-reduced-motion下的减弱动效。不覆盖库的提交和响应状态机，不持久化授权、不自动执行请求。

## 验证

- API清单31 项逐个进入文档；期望状态正确、查询/路径示例可用、不存在虚假的201/200占位响应。
- 真实HTTP检查 HTML、JS、CSS、本地OpenAPI JSON/YAML；14 个排除接口仍404，全部15 个占位仍501。
- 浏览器实际执行200配置、200场景、501占位和404不提供，查看响应正文；检查搜索无结果/恢复、键盘、窄屏与长JSON。
- 禁用OPENAPI的独立测试确认页面、原始文档和静态资源均404，公共API仍可用。
- 类型、lint、架构、格式和测试通过；Docker镜像内静态依赖及清单存在，Compose验证不回归。
